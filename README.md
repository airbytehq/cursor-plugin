# Airbyte Agents

Let AI agents query data and act across all your business apps via MCP.

Airbyte Agents gives your AI agent authenticated, real-time access to the platforms you use every day: your CRM, support desk, analytics tools, and more. Read, search, and write data across every connected system directly from Cursor.

## What you need

- An Airbyte Agents account. Sign up free at [app.airbyte.ai](https://app.airbyte.ai).
- [Cursor](https://cursor.com/) IDE.
- Credentials for the services you want to connect (e.g. Salesforce OAuth, a Linear API key).

## Getting started

1. Install the Airbyte Agents plugin from the Cursor Marketplace.
2. Open the chat panel and select Agent mode.
3. When Cursor connects to the MCP server, your browser opens. Log into your Airbyte account and grant access.
4. To connect a data source, ask the agent (e.g. "connect my Salesforce"). The agent starts a credential flow and gives you a URL to visit. Credentials are always entered in the browser, never in the chat.
5. Once connected, start asking questions about your data in natural language.

## Example prompts

- "Show me all open support tickets from the last 7 days"
- "What deals closed this quarter in Salesforce?"
- "Summarize recent commits on our main repo"
- "Send a Slack message to #engineering with the weekly pipeline summary"
